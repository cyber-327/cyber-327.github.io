Recall and Apply

Definitions and Formulas

Important Definitions

QAM (quadrature amplitude modulation)
Digital modulation that represents symbols using combinations of carrier amplitude and phase.
QPSK (quadrature phase-shift keying)
Four allowed phase states, representing two bits per symbol.
constellation
Plot of allowed or measured symbol points in in-phase and quadrature coordinates.
symbol
One signaling state that may represent one or more bits.
PRBS (pseudorandom binary sequence)
Reproducible, irregular-looking test bits. Match generator settings and align the reference with the received record before comparing.
BER (bit error rate)
Wrong recovered bits divided by aligned compared bits, at a stated measurement point and under stated test conditions.
EVM (error vector magnitude)
Symbol-position error relative to a stated reference. It is not a percentage of wrong bits.
RMS (root mean square)
Square the magnitudes, average them, then take the square root. Our EVM examples use supplied RMS magnitudes.
SNR (signal-to-noise ratio)
Desired signal power relative to noise power at the same receiver point and over the same bandwidth.
C/N (carrier-to-noise ratio)
Desired modulated carrier power relative to noise under a specified measurement convention and bandwidth.
FEC (forward error correction)
Added redundancy that lets a receiver correct some errors. The lecture's comparison records use no error-correcting code.
OFDM (orthogonal frequency-division multiplexing)
Combines many simultaneously transmitted subcarriers into one waveform. Each can carry a QPSK or QAM symbol.
subcarrier
One component frequency in the combined signal. A data subcarrier carries mapped bits; practical systems can reserve other components for reference signals or leave them unused.
orthogonality
Over the useful receiver observation interval, ideal subcarriers contribute zero to one another's measurements. Spectra may overlap; correct timing and frequency alignment matter.
useful interval T_u
The portion of an OFDM block analyzed by the receiver, excluding the cyclic prefix. It sets adjacent subcarrier spacing in the basic construction.
multipath and excess delay
Copies of a signal travel by different paths. Excess delay measures a path's arrival delay relative to the earliest reference path.
CP (cyclic prefix)
A copy of the useful block's tail placed at the front, then discarded before receiver analysis. It adds time without adding new message bits.
equalization
Estimating and compensating for the channel's amplitude/phase effects where feasible. It cannot recover information lost to overwhelming noise.
frequency selectivity and fading
The channel affects frequencies differently; a deep fade is a large reduction in received signal at a frequency.
intercarrier interference
Unwanted contribution from one subcarrier to another's decision, for example when frequency offset spoils ideal separation.
spread spectrum
Deliberately uses a wider frequency range than the underlying data modulation requires, through hopping or a faster spreading code.
FHSS (frequency-hopping spread spectrum)
Transmitter and receiver change channels together using an agreed timing and sequence.
DSSS (direct-sequence spread spectrum)
Combines data with faster code elements called chips; a synchronized receiver uses the same code to despread the signal.
chip
One short element of a spreading sequence, not an independent new message bit.
processing gain G_p
A spreading ratio, approximately spread bandwidth divided by the corresponding unspread data-signal bandwidth under consistent definitions. It is not a guaranteed improvement for every noise/interference condition.
adaptive modulation and coding
Coordinated changes to modulation order and error-control redundancy in response to channel conditions and service requirements.
capacity
An ideal limit on information rate for a stated channel model; it is not measured application throughput or proof that a particular receiver works.

Equations and Relationships

  • Bits per M-ary symbolbits/symbol = log2(M)
  • Mapped bit rateRb = Rs log2(M), before coding/framing/retry deductions
  • Measured bit error rateBER = erroneous bits / compared bits
  • Bit record lengthN = Rb T for a continuous stream at the stated measurement point; exclude startup and gaps
  • RMS EVM with ideal-reference normalizationEVM (%) = 100 × RMS error magnitude / RMS ideal-reference magnitude
  • Signal-to-noise ratio in dBSNRdB = Psignal,dBm - Pnoise,dBm, measured at the same receiver point and over the same bandwidth
  • Adjacent orthogonal subcarrier spacingΔf = 1 / Tu; Tu excludes the prefix
  • Total transmitted OFDM intervalTtotal = Tu + TCP
  • Mapped OFDM bit rate in the simplified exampleRb = Ndata log2(M) / (Tu + TCP), for Ndata identical M-ary data subcarriers and no other overhead
  • Information rateRinfo = Rb Rc, where Rc is the information fraction of the coded stream; subtract other overhead separately
  • Approximate spreading ratioGp approx Bspread / Bdata, using consistently defined spread and corresponding unspread signal bandwidths
  • SNR conversionS/N = 10^(SNRdB / 10), a linear power ratio
  • Shannon capacity for the ideal band-limited additive white Gaussian noise modelC = B log2(1 + S/N), with B in Hz and linear S/N
