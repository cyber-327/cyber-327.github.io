Definitions and Formulas

Important Definitions

parity
Extra bit indicating whether the number of one bits should be even or odd.
checksum
Compact value computed from data to detect some accidental changes.
CRC
Polynomial-based error-detection code effective at detecting common burst errors.
codeword
Complete transmitted block containing data and any added coding bits.
Hamming distance
Number of bit positions in which two equal-length codewords differ.
FEC
Added redundancy that lets a receiver correct some errors without retransmission.
interleaving
Reordering bits from different codewords to spread burst damage before decoding.
coding gain
Reduction in required energy-per-bit to noise-density ratio for a stated target error rate under specified coding and decoding conditions.
coded bit rate
Transmitted bit rate including the extra bits added by error-control coding.
information bit rate
Rate of information bits carried by the code, before other overhead and retries.

Equations and Relationships

  • Code rateRc = k / n
  • Redundancyn - k bits
  • Information bit rateRinfo = Rcoded × Rc
  • Random-remainder approximationPundetected ≈ 1 / 2r
Practice focus: Follow a remote sensor message through a noisy link. Add parity, test a byte-sum checksum, trace a small CRC, then distinguish detection from correction. Explain how block parity and interleaving address different error patterns. Finish by calculating the data-rate cost of redundancy and explaining why a passing check does not prove sender trust. Minimum-distance detection and correction formulas describe separate capabilities; a decoder does not automatically deliver both guarantees simultaneously. In the equations, k is the number of information bits, n is the total number of coded bits, and r is the number of CRC bits. The CRC probability estimate assumes approximately uniform remainders for random corrupted frames; it is not a guarantee for every error pattern or a probability of attacker success.
