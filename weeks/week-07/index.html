Recall and Apply

Definitions and Formulas

Important Definitions

PLL
Feedback system that makes an oscillator track the phase or frequency of an input.
clock recovery
Extraction of symbol timing from a received signal.
synchronization
Alignment of receiver timing, frequency, or phase with the incoming signal.
capture range
Frequency range over which a PLL can initially acquire lock.
lock range
Frequency range over which an already locked PLL can continue tracking.
receiver
System that selects, amplifies, and recovers information from an incoming signal.
sensitivity
Minimum input level required for a receiver to meet a stated performance target.
selectivity
Ability to accept a desired channel while rejecting nearby signals.
dynamic range
Span between the weakest usable signal and the strongest signal the receiver can handle without unacceptable distortion.
overload
Condition in which a strong input drives a receiver stage outside its useful operating region.
sampling
Measuring a continuous-time signal at discrete instants.
quantization
Mapping each sample to one of a finite set of amplitude levels.
ADC
Device that converts an analog input into a digital code.
DAC
Device that converts a digital code into an analog output.
reconstruction
Recovery of a continuous-time waveform from samples.
aliasing
False frequency representation caused by sampling too slowly.
false telemetry
Plausible-looking digital measurements that do not represent the true physical input.
anti-alias filter
Analog low-pass filter used before sampling to reduce frequencies that could alias.
analog truth
Physical input waveform used as the reference when evaluating sampled data.
