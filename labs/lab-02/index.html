Lab 02 · Week 2 · September 11, 2026

Measurement Integrity and Power Signatures

Parallel loads, instrument loading, and trustworthy waveform measurements

Learning Outcomes

By the End of This Lab

  • Predict and measure how an added parallel load changes equivalent resistance, source current, and total power
  • Explain how finite instrument input resistance changes the circuit being measured
  • Configure a function generator and oscilloscope to produce and measure a repeatable sine wave
  • Recognize incorrect probe attenuation and AC/DC coupling as measurement-configuration problems
  • Separate the physical signal, the instrument configuration, the displayed result, and the conclusion drawn from it

The Big Picture

What You Are Doing

  1. Extend the Lab 1 predict-measure-compare method to a circuit with parallel loads.
  2. Treat source-current change as a simple electrical signature of device state.
  3. Compare a high-value divider with no instrument, a DMM, a 1x probe, and a 10x probe.
  4. Generate a known sine wave and verify its amplitude, frequency, RMS value, and offset.
  5. Create and correct two controlled configuration errors that make a healthy signal look wrong.

Before Lab

Preparation

  • Review the Week 2 definitions and formulas for parallel resistance, branch current, loading, amplitude, period, frequency, RMS, and offset
  • Bring a calculator and open the Lab 2 report before beginning
  • Recall the Lab 1 rules: power off before rewiring, resistance is measured only on a de-energized circuit, and current mode is never placed across a source

Bench Setup

Equipment and Materials

  • Digital multimeter with DC voltage, DC current, resistance, and AC voltage modes
  • Current-limited DC power supply with red and black leads
  • Two-channel oscilloscope with one switchable 1x/10x probe
  • Function generator with BNC-to-clip or BNC-to-probe connection
  • Solderless breadboard and jumper leads
  • Two 100 kΩ resistors, one 1.0 kΩ resistor, and one 2.2 kΩ resistor
  • Calculator

Follow These Steps

Lab Walkthrough

Set Up The Bench

  1. Open the Lab 2 report and enter your name and lab partners.
  2. Find the DMM, power supply, oscilloscope, function generator, probe, breadboard, leads, and resistors. Record instrument model numbers in the report and ask about missing or damaged equipment.
  3. Keep the power-supply and function-generator outputs disabled. Set the supply to 5.00 V with a 25 mA current limit using the instructor-approved procedure.
  4. Put the DMM black lead in COM and the red lead in V/Ω. Do not move the red lead to a current jack until the procedure explicitly tells you to do so.
  5. Set the physical oscilloscope probe switch to 10x, set the channel probe factor to 10x, and connect the probe ground clip only to circuit common. The oscilloscope ground clip must never be moved to the supply-positive rail or a divider midpoint.

Build The Parallel-Load Circuit

  1. With the supply output disabled, build two resistor branches from V+ to G: Branch 1 contains R1 = 1.0 kΩ; Branch 2 contains R2 = 2.2 kΩ and can be connected or disconnected with a jumper.
  1. Measure each resistor while it is isolated and de-energized. Record the measured values in Table 1, then reconnect the circuit.
  2. For State A, leave Branch 2 disconnected. Predict equivalent resistance, Branch 1 current, total source current, and total power.
  3. For State B, connect Branch 2 in parallel. Predict equivalent resistance, both branch currents, total source current, and total power.
  4. Before applying power, explain why adding Branch 2 must decrease equivalent resistance and increase total source current.

Measure The Two Load States

  1. Confirm the DMM is still configured for DC voltage. Enable the supply and verify approximately 5.00 V across V+ and G.
  2. Measure the voltage across Branch 1 in State A and across both branches in State B. Parallel branches should share approximately the same voltage.
  3. Disable the supply before measuring current. Move the red DMM lead to the instructor-approved current jack, select a safe DC-current range, and open the source path at V+.
  4. Insert the DMM in series with the entire circuit, enable the supply, and record total current for State A. Disable the supply before connecting Branch 2, then repeat for State B.
  5. Disable the supply, remove the DMM from the source path, restore the circuit, and immediately return the red lead to V/Ω.
  6. Complete Table 1. Treat the difference between State A and State B current as a simple power signature: an observer can distinguish load state without seeing what the second branch represents.
  7. Take one photograph showing the completed two-branch circuit and one photograph showing the State B total-current measurement.

Build The Loading Divider

  1. Disable the supply and remove the parallel-load circuit. Build a divider using Rtop = 100 kΩ from V+ to Vout and Rbottom = 100 kΩ from Vout to G.
  1. Calculate the ideal unloaded Vout. Then use the nominal input resistances provided by the instructor to predict Vout with the DMM, 1x probe, and 10x probe connected one at a time.
  2. For each instrument, treat its input resistance as parallel with Rbottom. Record the nominal input resistance, effective lower-leg resistance, and predicted voltage in Table 2.
  3. Enable the supply. Attach only one measuring instrument at a time between Vout and G; attaching the DMM and oscilloscope together creates another loading condition.
  4. Measure Vout with the DMM, the oscilloscope probe in 1x mode with the channel set to 1x, and the probe in 10x mode with the channel set to 10x. Return the probe to 10x when finished.
  5. Record each result and calculate loading error relative to the ideal unloaded voltage. If the instrument specifications differ from the nominal values, use the actual documented input resistance and note the change.
  6. Take one photograph showing the divider and one screenshot or photograph showing a loaded Vout measurement.

Learn The Function Generator And Oscilloscope

  1. Disconnect the DC divider from the instruments. Connect function-generator signal to the oscilloscope probe tip and generator ground to the oscilloscope ground/reference as shown.
  1. Set the generator to a sine wave at 1.00 kHz, 2.00 Vpp, and +1.00 V offset. Use the generator's High Z load setting when available. If it has no load setting, adjust amplitude until the correctly configured oscilloscope measures approximately 2.00 Vpp and record the generator configuration.
  2. Keep generator amplitude at or below 5.00 Vpp and verify that the displayed waveform remains within the instructor-approved voltage range.
  3. Set the oscilloscope channel to DC coupling, 10x probe factor, approximately 500 mV/div, and approximately 200 µs/div. Adjust trigger level until the waveform is stable.
  4. Measure and record Vpp, peak amplitude, maximum, minimum, DC offset, period, and frequency in Table 3. Calculate the expected AC RMS value and compare it with the oscilloscope measurement if available.
  5. Set the DMM to AC voltage and measure the same generator output without changing generator settings. Record the reading and the meter's stated AC bandwidth or note that it is unknown. A difference from the scope does not automatically mean either instrument is defective.
  6. Save or photograph one clear baseline waveform with volts/div, time/div, probe factor, coupling, and measured values visible.

Configuration Challenge 1: Probe Factor Mismatch

  1. Record the correct baseline amplitude before changing anything.
  2. Leave the physical probe switch at 10x, but deliberately set the oscilloscope channel probe factor to 1x. Do not change generator amplitude.
  3. Record the displayed amplitude and compare it with the baseline. Explain why the display is wrong even though the electrical signal did not change.
  4. Restore the channel setting to 10x, verify the baseline amplitude returns, and record the correction in Table 4.

Configuration Challenge 2: Coupling Hides The Offset

  1. With the correct 10x probe configuration restored, record the DC-coupled waveform's Vpp and offset.
  2. Change only the oscilloscope channel from DC coupling to AC coupling. Record what happens to the displayed offset and what remains approximately unchanged.
  3. Explain why AC coupling can be useful but can also hide an important DC component. Restore DC coupling and confirm the original display returns.
  4. Save or photograph one challenge waveform with the relevant scope setting visible and complete Table 4.

Finish And Submit

  1. Complete all four content tables and verify units, settings, predictions, and measured results.
  2. Complete the Evidence section with five readable photographs or screenshots: parallel circuit, State B current, loaded divider, baseline waveform, and one configuration challenge.
  3. Complete the Conclusion in your own words. Explain the load-state signature, the largest loading error, one configuration error, and what evidence supports each conclusion.
  4. Disable both source outputs. Set the power supply to its storage state, return the scope to DC coupling and 10x, return the DMM leads to COM and V/Ω, remove components, and restore the bench.
  5. Save the completed report, export it as a PDF, and submit the PDF through Learning Suite.

Why This Lab Matters

  • Device operating states can produce repeatable current and power signatures even when payload data is unavailable
  • Measurement tools become part of the circuit and can create apparent anomalies that are not device faults or attacks
  • Incorrect probe factors, coupling modes, references, and generator settings can produce persuasive but false evidence
  • Trustworthy signal analysis requires recording both the physical connection and the instrument configuration
