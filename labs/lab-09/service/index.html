I_RX and Q_RX each have one selected capacitor to GND: REF = 100 nF; CHALLENGE = 33 µF electrolytic, positive at the signal junction and negative at GND. Disconnect USB before circuit changes. Use USB power and leave AREF unconnected.

Nominal logic high depends on actual supplies and loading. Measure high and low levels before choosing thresholds. Optional indicators: RX D4 red / A5 green, each with a separate 330 Ω resistor.

02 / Symbol register

I is horizontal, Q vertical. The voltages hold their levels for each symbol interval (NRZ level signaling); repeated states have no required return to zero. Each I/Q state carries two bits.

I levelQ levelBits
HighHigh00
LowHigh01
LowLow11
HighLow10

Read four pairs per byte, most-significant bit first. At 200 symbols/s, each symbol occupies 5 ms. X–Y shows possible states; Normal time mode preserves their order. Mapped bit rate = symbol rate × log₂(number of states).

03 / Capture and framed operation

CAPTURE: a four-byte maintenance message, 16 symbols at 200 symbols/s. Both outputs first go low. The first symbol raises Q, providing a rising-edge trigger on CH2. The burst contains payload only, lasts 80 ms from first symbol to end, then returns both outputs low and stops. No header or CRC is present in this burst.

START: continuously alternates a known training frame and a DATA or RECOVERY frame. Use this stream for X–Y inspection and receiver RUN measurements. The receiver confirms valid INTERCEPT data without revealing its contents.

Framed format: D3 91 | TYPE | LENGTH | PAYLOAD | CRC8. Types (hex): 54 training, 44 intercepted data, 52 recovery data. LENGTH counts payload bytes. CRC-8/SMBUS covers TYPE, LENGTH and PAYLOAD: polynomial 07, initial 00, input/result reflection No, final XOR 00. Training contains 128 known bytes. The receiver finds the frame marker automatically.

05 / Measurement and recovery

On the DSOX2012A: CH1 = I_RX, CH2 = Q_RX; DC coupling, matching 10× factors. Select Horiz → Time Mode → XY for state groups. To capture time order, use Normal mode. For CAPTURE, stop TX, select 10 ms/div, choose CH2 rising-edge triggering at the measured Q midpoint, and put the trigger near the left edge with at least 80 ms after it. Arm Single before sending CAPTURE.

RX needs RATE and THRESH before RUN. A stage or configuration change clears qualification. BER = wrong aligned training bits / compared aligned training bits; unavailable comparison is not zero errors. A CRC match does not authenticate the sender.

Recovery confirmation needs a valid received RECOVERY payload and two fresh complete training runs under unchanged settings, each meeting mapped rate ≥80 bit/s and observed BER ≤0.01. Keep the changed filter connected and retain waveform and count evidence.
