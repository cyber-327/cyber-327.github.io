2. Device reference

Open wiring schematic

Probe I_RX on CH1 and Q_RX on CH2. Use matching 10× settings and DC coupling. On the DSOX2012A select Horiz → Time Mode → XY for state groups, then return to Normal mode for time order. Measure the SYNC period to obtain the symbol interval.

Frame: D3 91 | TYPE | LENGTH | PAYLOAD | CRC8. The two-byte marker establishes byte alignment. LENGTH counts payload bytes. Types: 54 training, 44 intercepted data, 52 recovery data (all hexadecimal).

Pack four bit pairs per byte, most-significant bit first. The receiver checks CRC-8/SMBUS over TYPE, LENGTH and PAYLOAD: polynomial 07, initial 00, no input/output reflection, final XOR 00. Training uses 128 known payload bytes.

Mapped bit rate = symbol rate × log₂(number of states). Observed BER = wrong aligned training bits ÷ compared aligned training bits. Framing overhead is separate from mapped rate. A CRC match is not a sender-authentication check.

3. Console reference

Open separate Arduino IDE Serial Monitor windows for TX and RX: 115200 baud, 8-N-1, Newline. Commands are uppercase. This workbench does not connect to USB or transmit commands.

ConsoleCommandPurpose
BothHELP / STATUSCommand syntax / current settings.
TXSTART / STOPBegin or stop the repeating stream. TX boots stopped.
BothRATE 25, RATE 50, or RATE 200Set symbols per second. Coordinate both boards.
TXHOLD 00 (or 01, 11, 10)Hold one state for voltage measurements; timing stops. Use START afterward.
RXPHASE pSample p percent after SYNC; integer 5–90. Default 50.
RXTHRESH i qI and Q decision thresholds in millivolts, chosen from measurements. Both must be positive and below VREF.
RXVREF vMeasured receiver supply in millivolts, integer 1000–5500. Default 5000. Does not change physical supply voltage.
RXRUNStart a fresh comparison of the next complete 1,024-bit training payload; allow up to 90 seconds.
RXRESETCOUNTSClear counts, cached recovery data and qualifying runs; keep settings.

RX needs RATE and THRESH before RUN. Wait for the received stage announcement before starting its measurements. Changing a setting or received stage resets qualification. Record failed checks and timing/alignment failures as well as bit counts; BER is unavailable when no bits were compared.

Two fresh qualifying runs under the same settings and a valid recovery message are required for recovery confirmation. Preserve evidence that the challenge channel stayed connected.
