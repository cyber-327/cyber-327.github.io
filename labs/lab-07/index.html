ADC Sampling, Aliasing, and False Telemetry

Use an Arduino Nano and an oscilloscope to compare the real input with sampled measurements, create a false alarm, and test a higher sampling rate

Learning Outcomes

By the End of This Lab

  • Check a 10-bit ADC against two measured DC voltages
  • Compare the input frequency on the oscilloscope with the Nano's apparent frequency
  • Predict how a signal above the Nyquist limit can appear at a lower frequency
  • Demonstrate a false decision in a toy alarm, then test a higher sampling rate
  • Explain why a valid digital measurement does not prove physical accuracy or sender identity

The Big Picture

What You Are Doing

  1. Your function generator represents a sensor input. The oscilloscope measures the physical signal, and a preloaded Nano samples A0 and prints its interpretation.
  2. Check the ADC with two DC levels, then compare a 200 Hz sine with a 1,800 Hz sine at the lower sampling rate.
  3. Run a toy alarm scenario using one generator. Change the source to model an unwanted input; do not connect two generator outputs together.
  4. Increase the sampling rate without changing the unwanted input, check that a genuine 200 Hz input can still be detected, and restore the baseline.
  5. This is an ADC/sampling activity: no physical DAC output, radio, antenna, or new Arduino code is required. Each student submits an individual report.

Before Lab

Preparation

  • Review ADC step size, sample rate, Nyquist limit, alias frequency, and peak-to-peak voltage.
  • Open the Lab 7 report. Your instructor programs and checks the classic 5 V, 16 MHz ATmega328/P Nano before class.
  • Use Arduino IDE 2 on the computer connected to your Nano. If it is not installed, complete the Before Lab installation steps below before class; use the existing copy on a prepared lab computer when available.
  • Open Serial Monitor at 115200 baud. Send ? for help; 2 selects 2,000 samples/s and captures, 5 selects 5,000 samples/s and captures, and c takes another capture at the selected rate.
  • Send d only if you want the last 256-sample capture as CSV. It does not take a new measurement. Send c after every source change; old results do not update automatically.

Bench Setup

Equipment and Materials

  • Per team: preloaded classic Arduino Nano, USB data cable, and computer with Arduino IDE 2 (includes Serial Monitor)
  • Function generator with adjustable DC offset and an approved BNC-to-clips lead
  • Two-channel oscilloscope, two 10x probes, and DMM with voltage leads
  • Breadboard, jumper wires, and one 3.3 kohm series resistor
  • Calculator or spreadsheet; use only instructor-validated captures if the live setup is unavailable

Optional or Specialized

  • 100 nF non-polarized capacitor for the low-pass extension after the required experiment

Circuit and Limits

Use This Configuration

  • Generator Output through 3.3 kohm to A0; generator shield, Nano GND, and scope grounds share common GND. Scope CH1 observes the generator side and CH2 observes A0.
  • Check the generator on the scope with A0 disconnected first. Output off for rewiring; USB power on before applying input, Output off before unplugging USB. The resistor is not complete overvoltage protection.
  • Verified sine target: 1.00 Vpp with +2.50 V offset, about 2.00-3.00 V. DC targets: about 1.00 and 3.00 V. Never apply negative or above-supply input, and leave AREF unconnected.

Follow These Steps

Lab Walkthrough

Before Lab: Install Arduino IDE and Open Serial Monitor

  1. Arduino IDE is the desktop application used to upload the sketch and read the Nano through its built-in Serial Monitor. In this lab, the instructor uploads the sketch; students use Serial Monitor and do not write code. Only the computer connected to each team's Nano needs the application.
  2. If Arduino IDE 2 is already installed, open it and skip the download. Otherwise, go to the official Arduino software page and choose the stable Arduino IDE 2 download for your computer, not App Lab, PLC IDE, or a nightly build.
  3. Windows: download the installer, open the .exe file, follow its prompts, and launch Arduino IDE. On a managed lab computer, ask the instructor or IT to install it rather than changing administrator or security settings.
  4. macOS: download the version matching your Mac (Apple Silicon or Intel), open the .dmg file, drag Arduino IDE to Applications, and launch it.
  5. Linux: download the supported AppImage, allow it to run as a program in the file's Properties / Permissions, and open it. If a dependency or USB-permission error appears, ask the instructor or IT; do not run the IDE as root. See Arduino's installation guide for OS-specific help.
  6. Finish first-launch setup while you have internet access. Open Boards Manager, search for Arduino AVR Boards by Arduino, and install it if missing. Then choose Tools > Board > Arduino AVR Boards > Arduino Nano. Do not choose Nano Every, Nano 33, or Nano ESP32.
  7. Leave the generator disconnected or its Output off. Connect the preloaded Nano by a USB data cable and choose its port under Tools > Port or the board/port selector. If no port appears, try a known data cable and ask the instructor before installing drivers. Do not upload Blink or another sketch over the preloaded lab program.
  8. Choose Tools > Serial Monitor, set 115200 baud, and allow the board to restart. Type ? in the message box and press Enter; check that the sampler help appears. If text is garbled, recheck the baud rate. Close any other application using the same serial port. Internet is needed for installation/downloads, not normal USB sampling once setup is complete.

1. Check the Connections and Sample Timing

  1. Keep generator Output off. With the A0 jumper initially disconnected, check the source on the scope. Connect generator Output center/red through 3.3 kohm to A0 only after the levels are verified; join generator shield/black, Nano GND, and scope grounds at common GND.
  2. Power the Nano by USB before enabling the verified input. Scope CH1 observes the generator side of the resistor; CH2 observes A0. Use 10x probes, matching probe factors, DC coupling, and high-impedance scope inputs, not 50 ohms.
  3. Use High Z load display on the generator; it is a display convention, not a change in output resistance. Leave modulation, sweep, burst, and the optional capacitor off. Use the main Output, not Sync.
  4. Record the board, measured reference voltage, 10-bit resolution, resistor, scope settings, and instrument IDs. Intended DC inputs are about 1 and 3 V; sine inputs are 1.00 Vpp with +2.50 V offset, about 2.00-3.00 V. Verify actual high/low levels within the board's permitted range before each connection. Never use negative voltages, RF carriers, VIN, 5V, or AREF as the signal input.
  5. For the timing check only, move CH2 to D8 with Output off while reconnecting. Send 2, then 5, and measure spacing between consecutive rising edges in each burst. Calculate actual sample rate = 1 / edge spacing. D8's high time is conversion time, not the sample interval. D8 is an output: never connect it to A0.
  6. Record both intervals/rates in the report and check overruns = 0. Return CH2 to A0 with Output off. If timing, input range, or wiring is uncertain, stop and ask the instructor; do not trust the frequency display yet.

2. Check the ADC with Two DC Voltages — Table 1

Evidence Photo

Save the higher DC-point DMM voltage and Nano mean code, with the reference voltage identified.

  1. Using the approved source, apply about 1.00 V DC through the resistor. Verify A0 voltage with the DMM, send 2, and record mean_code, not min_code or max_code.
  2. Turn Output off before changing connections or settings. Repeat at about 3.00 V DC. Keep both inputs inside the verified board range.
  3. Calculate step size = measured Vref / 1024 and predicted code = measured input / Vref x 1024. Use the measured values, not an assumed exact 5.00 V reference. Calculate code error = reported mean code - predicted code.
  4. DC has no tone frequency: an N/A frequency or INVALID tone/alarm message is expected here. Use the voltage/code results for calibration and investigate unexplained errors before continuing.

3. Measure a Faithful Sine Wave — Table 2

  1. With Output off, select sine, 200 Hz, 1.00 Vpp, +2.50 V offset, and High Z load display. Keep the capacitor disconnected. Recheck the physical high/low voltages before proceeding.
  2. Send 2 to capture at 2,000 samples/s. Record the actual scope frequency and the Nano's apparent_frequency_Hz. Calculate the Nyquist limit = sample rate / 2 and make your frequency prediction before comparing it with the Nano result.
  3. Check that overruns is zero, near_rail_warning is NO, and the sine result is valid. The sketch estimates a single sine's frequency from rising midpoint crossings; it is not an FFT or a general audio decoder.
  4. Optional: send d and plot the last capture's estimated voltage against time. Dots are measurements; a line joining them is not a physical DAC output.

4. Create an Alias, Then Change the Sampling Rate — Table 2

Evidence Photo

Save the scope frequency and the corresponding lower-rate Nano capture together; identify the source and sample rate.

  1. Keep the Nano at 2,000 samples/s. Turn Output off, change only the sine frequency to 1,800 Hz, and recheck the voltage settings.
  2. Verify the real input on the scope. Use an adequate scope sample rate, such as at least 100,000 samples/s, so the scope is a useful independent reference; record the rate actually used.
  3. Predict the apparent frequency using f_alias = abs(f_input - k x f_sample), choosing integer k so the result lies from zero to f_sample/2. Then send c and record a fresh result.
  4. Leave the 1,800 Hz source unchanged and send 5. Predict and record the higher-rate result. For all three Table 2 rows calculate absolute frequency error = abs(Nano frequency - scope frequency).

5. Run the Toy Alarm Scenario — Table 3

Evidence Photo

Preserve the baseline, substituted, higher-rate, positive-control, and restored results before changing each condition.

  1. The alarm is text, not a physical actuator. It prints ON only for a valid apparent frequency from 180 to 220 Hz with estimated amplitude at least 0.50 Vpp. Clipping/near-rail warnings, weak signals, or overruns are not successful controls.
  2. Use the same single generator and the same 1.00 Vpp / +2.50 V sine settings throughout. This is source substitution, not simultaneous injection into a real sensor. Do not combine generator outputs.
  3. Baseline: set 400 Hz and send 2. Record actual scope frequency, Nano frequency, Nano Vpp, the printed alarm state, and frequency error.
  4. Substituted input: change the source to 1,800 Hz, leave the lower sample rate selected, and send c. Record a fresh scope/Nano comparison and alarm decision.
  5. Higher-rate control: leave the 1,800 Hz source unchanged and send 5. Record the result and quantify how the measured frequency error changes. Higher-rate sampling does not remove the physical input.
  6. Positive control: at the higher sampling rate, set a genuine 200 Hz input and send c. Check whether the valid alarm can still activate. An OFF result from disconnecting or invalidating the signal does not demonstrate a useful mitigation.
  7. Restored baseline: return to 400 Hz and send 2. Record the result before clearing settings. Explain why resolving this alias does not authenticate a sensor or prevent a genuine unwanted 200 Hz input.

Optional Extension: Add an Analog Low-Pass Filter

  1. Only after the required higher-rate experiment works, turn Output off and connect a 100 nF capacitor from A0 to common GND. Keep the 3.3 kohm series resistor in place. The capacitor is not a series DC block in this experiment.
  2. Use 2,000 samples/s and the same source amplitude/offset. Compare the generator-side and A0-side scope Vpp at 1,800 Hz, then at the genuine 200 Hz input; take a fresh Nano capture for each condition.
  3. Calculate amplitude reduction = 100 x (1 - Vpp_after / Vpp_before). Check whether the desired input remains usable. Distinguish reducing unwanted amplitude from removing an alias or proving authenticity. This extension adds no required graded table.

6. Explain the Result and Finish

  1. Complete the three content tables, evidence captions, and conclusion. Use measured results and record any warnings; do not replace unexpected data with theoretical values.
  2. Rotate equipment operator, scope observer, and recorder roles. Each student submits their own report as a PDF through Learning Suite.
  3. Disable generator Output before removing leads or unplugging USB. Remove the optional capacitor, return the station to its posted baseline, and return the equipment. Never lift protective earth on the scope or generator.

Why This Lab Matters

  • A plausible digital number can misrepresent the physical input if sampling is inadequate
  • If an attacker can introduce a suitable analog disturbance, an alias may contribute to a false software decision; this bench model does not establish real-device exploitability
  • Higher-rate sampling resolves the chosen frequency ambiguity; it does not remove interference or authenticate a sensor
  • A valid positive control distinguishes a useful change from simply disabling the measurement
