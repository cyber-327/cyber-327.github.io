Packet workbench

Decode the clues. Build a packet. Test your reasoning on the controller.

DC-08 packet tools. Construct a packet, then transmit its hex text through Serial Monitor at 115200 baud, 8-N-1. This workbench does not transmit packets.

1. Hex ↔ ASCII

Nonprintable bytes are displayed as ·. Their original values stay in the hex input. Decoded text is never executed or opened automatically.

2. Eight-byte message

Enter the 16 hex digits from your capture. Each pair is one byte. Bytes 0–6 are checked; byte 7 stores the check. Use the service schematic for command syntax and the current patch's check rules.

Type continuously: each valid hex digit moves to the next box. Arrow keys move between boxes; pasting spreads digits across boxes. Checked means locked for searching, not typing. All locks start unchecked; loading a packet preserves your lock choices.

Vary extra bytes only sets the search locks: ID, command and CRC stay fixed; bytes 5–6 can vary. It does not change any packet values or start a search.

Enter a packet to inspect.

CRC calculator · width 8 bits

Enter all five parameters from the current patch notes. Numeric parameters are hexadecimal; use the normal polynomial representation, omitting the implicit x⁸ term. CRC calculation covers bytes 0–6 only.

Enter the CRC parameters and a packet. Calculation does not change the packet.

3. Fixed-CRC collision search

This is the same frame as the message editor above. Values and locks stay synchronized in both directions.

Set the desired command first. Lock the device ID, command, and both target CRC digits. Leave the two extra bytes adjustable, or use Vary extra bytes only to set these locks. The search keeps every locked digit unchanged and never returns the starting packet.

The search uses the five CRC parameters entered above. The target is byte 7; the CRC covers bytes 0–6 only. Inspect the result's command before transmitting: a matching LOCK packet does not execute OPEN.

Search again or choose Next collision to move through different matches. After the last match, results cycle back to the first. Editing a value or lock starts a new search.

No search started. At most four digits may be unlocked (65,536 candidates).

Send the displayed hex text plus a newline at 115200 baud, 8-N-1. The controller decodes that text into eight bytes. Use INIT in the correct packet syntax to start the capture stream. Search runs locally; it does not transmit trial packets.
